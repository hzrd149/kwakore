    - A nonempty batch returns an array of only response-bearing members; an empty batch returns one Invalid Request object; a notification-only batch and a valid individual notification return no bytes even when the dispatch callback changes state.
    - Duplicate object keys, trailing JSON, invalid ID types, oversized frames and batches, reserved rpc. methods, and malformed params fail predictably; different connections can continue after one bad frame.
  </behavior>
  <action>Implement one complete JSON value per newline and multiple sequential frames per connection. Preserve the raw ID for exact echo, accepting JSON-RPC string, number, and null IDs; treat absent ID as a notification only after the request envelope is valid. Decode named parameter objects strictly per method; reject duplicate envelope keys as -32600 and duplicate/unknown param names as -32602. Support batches and notifications exactly as in the JSON-RPC 2.0 specification, including executing valid notification methods without responding; test this with a mutating fake dispatch callback and a mixed batch. Define fixed standard error messages plus an application code catalog outside the reserved negative range: 1001 unauthorized, 1002 not_found, 1003 busy, 1004 unavailable, 1005 no_update, 1006 config_invalid, 1007 closing, 1008 timeout, 1009 conflict, 1010 confirmation_required, 1011 partial_cleanup. <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local process to Unix listener | Filesystem access is untrusted; kernel peer UID authenticates each accepted connection. |
| JSON line to method dispatcher | Every byte and JSON member is untrusted and bounded before dispatch. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-07-01 | Spoofing | socket_linux.go | high | mitigate | 0700 runtime path, 0600 socket, SO_PEERCRED UID equality before decode |
| T-07-02 | Tampering | socket_linux.go | high | mitigate | Hold daemon lock, probe existing socket, unlink only owned stale inode, compare inode on close |
