<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Signer transition to concurrent NAP operation | Mutable identity crosses goroutine boundaries while untrusted napplet calls arrive. |
| Hardened child to daemon | A real child and its host page must preserve bridge token, sandbox, and permission enforcement. |
| CI environment to graphical test | Display server, built child, and checked native library are external prerequisites that must fail closed when absent. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-20 | Elevation of privilege | identity globals | high | mitigate | Synchronized pair publication and snapshot reads across all production consumers; targeted race and stale-generation tests. |
| T-08-21 | Information disclosure | NAP signer failures | high | mitigate | Preserve fixed NAP failure shapes and captured-log leak assertions during switch/logout. |
| T-08-22 | Tampering | real child bridge | high | mitigate | Run the existing hardened host page, token binding, route gate and prompt-owner tests through the daemon Linux Host under the required desktop.yml graphical gate. |
| T-08-23 | Denial of service | graphical child lifecycle | medium | mitigate | Bounded ready/close waits, child reap, headless preflight and TestRPCRealChildGraphical under xvfb-run. |
| T-08-24 | Repudiation | CI smoke result | medium | mitigate | Require a named TestRPCRealChildGraphical PASS line with pipefail; required-graphics mode fatals on missing display, executable or native library. |
</threat_model>
