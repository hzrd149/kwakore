<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Remote NIP-46 signer to daemon | Remote events and errors are untrusted and may contain attacker text; pairing must verify the one-time secret. |
| CLI-generated pairing token to socket | Secret enters only a write request and remains in memory until completion/cancel. |
| Credential store to resumed session | Client key and bunker URL must stay private and consistent across restart. |
