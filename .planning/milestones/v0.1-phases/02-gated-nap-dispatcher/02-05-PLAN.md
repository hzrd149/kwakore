<objective>
Make the host page's fallback answers (for requests that never reached Go: too large, unencodable, too many pending, rpc failure) use exactly the failure shapes Go's route table declares, and prove both sides build identical envelopes. Record the DISP-02 fixes in the conformance checklist.

Purpose: DISP-02 says "in both Go and the host page fallback". Today `refuse()` answers every type with `<type>.result {ok:false}`, which hangs `inc.channel.list`, breaks `intent.invoke`, violates identity.getPublicKey's MUST, and answers `resource.cancel` and unknown types it must not answer (02-RESEARCH Pitfall 3).
Output: `FAIL_SHAPES` and a table-driven `refuse()` in napplet-host.js, `backend/nap_failshape_test.go`, the shared fixture, node-backed host page tests, and checklist rows.
</objective>
