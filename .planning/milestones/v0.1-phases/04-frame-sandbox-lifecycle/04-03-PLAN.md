<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| launcher preamble -> napplet frame | trusted code runs inside the untrusted document before the napplet's own scripts |
| napplet frame -> host page | the frame (and any document that replaces it) can post any message, including a forged marker |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-13 | Spoofing | reloaded document's pre-load envelopes accepted under the old session (RESEARCH C2) | high | mitigate | preamble marker precedes every napplet script; second marker -> replaced() before any envelope of that document is enqueued (Task 1) |
| T-04-14 | Tampering | napplet forging the marker | low | accept | only forces its own rebuild, counted by the D-03 cap; the marker is never forwarded or answered (Task 2) |
| T-04-15 | Elevation of privilege | marker code leaving a callable global in the frame | high | mitigate | posted inside the function scope; scope probe asserts globals are exactly [napplet] and one post (Task 2) |
| T-04-16 | Tampering | napplet suppressing the marker in a reloaded document | medium | mitigate | nothing of the napplet runs before the preamble; load counting (04-01) remains the fallback |
</threat_model>
