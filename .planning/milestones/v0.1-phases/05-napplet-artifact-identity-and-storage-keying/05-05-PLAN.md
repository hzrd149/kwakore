<objective>
Pick the latest manifest event by NIP-01 rules before validating it, and show an invalid latest as unavailable instead of falling back (REG-01; D-10, D-16, D-22), on every discovery, address-lookup and author-page path. The update paths follow in 05-06.

Purpose: today every site keeps the newest valid event and compares created_at only, so a newer invalid event silently falls back to an older version (W-3), and nothing breaks created_at ties. NIP-01: “In case of replaceable events with the same timestamp, the event with the lowest id (first in lexical order) should be retained, and the other discarded.” A relay can forge the id field to win ties unless CheckID runs first (RESEARCH Pitfall 1).
Output: registry_select.go, Napp.EventID/Unavailable, the reason catalogue, converted discovery/address/detail sites, tests.
</objective>
