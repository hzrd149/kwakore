<objective>
Validate `source` by the rules of the manifest's own schema (REG-02; D-11, D-18) and send manifest blob downloads through the public-internet guard with a size cap and timeouts, trusting only the Blossom servers the user configured (D-12, D-20).

WEB-NAPPLET: “`source` values MUST be absolute `https://`, `ssh://`, `git://`, or `nostr://` URLs.” and “A malformed optional metadata tag (`icon` or `source`) MUST be ignored without invalidating an otherwise valid event.”
Output: guarded and trusted blob clients with caps, per-schema source validators, tests.
</objective>
