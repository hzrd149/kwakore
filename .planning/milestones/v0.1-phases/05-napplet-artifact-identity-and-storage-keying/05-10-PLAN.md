<objective>
Reclaim what superseded hashes, uninstalled napplets and deleted window instances leave behind (KEY-05; D-05, D-06, D-07, D-24), sweep unowned storage and config files once at startup (D-08), and make rule and usage ids injective so uninstall removes exactly the right rules (KEY-03, RESEARCH Pitfall 9).

Purpose: every new artifact hash and window instance creates a new namespace file that is never removed today (S-3), Uninstall leaves storage, config and rules behind and does not close windows, and a d containing 0x1F corrupts rule parsing. NAP-STORAGE: “Instance storage lives as long as the instance; the shell MAY reclaim it on destroy.”
Output: reclaim helpers with deferral and dead stores, reclaim on uninstall/update/overwrite/window delete, the startup sweep, escaped rule and usage ids, tests.
</objective>
