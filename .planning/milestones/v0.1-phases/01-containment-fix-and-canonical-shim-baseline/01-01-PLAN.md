<objective>
Close the live `d`-tag path escape (CRIT-01, gap W-1). Today `filepath.Join(dataDir, "napps", id)` turns `d="../../.."` into `{dataDir}` itself, so a failed install or an uninstall runs `os.RemoveAll(dataDir)` and wipes `state.json`, the keys and the event store; `d="/../x"` lands in another napp's namespace and `d="a/b"` nests under napp `a`. This plan makes `nappBaseDir` the one hashed, contained choke point (D-01, D-02, D-03), routes every caller through it, gives asset sub-paths their own containment rule, and pins it all with a regression matrix (D-05). This ships first in the phase, before any audit work (roadmap; orchestrator decision 6).

Purpose: no napp or napplet `d` tag can read, write or remove anything outside `{dataDir}/napps/{hash}`, while `d` stays byte-exact in identity, storage keys and wire messages.
Output: hardened `backend/backend.go` choke point, converted call sites, deleted exported `NappBaseDir`, `backend/containment_test.go`.
</objective>
