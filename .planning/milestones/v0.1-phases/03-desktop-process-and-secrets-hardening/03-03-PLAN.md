Per D-01/D-02 create package desktop/internal/childbin (package doc: why the dir is per-user and why every spawn re-hashes). Types and functions:
- File struct { Name string; Data []byte; Sum [32]byte; Exec bool }.
- CacheDir() (string, error): filepath.Join(os.UserCacheDir(), "Verdana", "child").
- Ensure(dir string, files []File) error, serialized by a package sync.Mutex. Steps: os.MkdirAll(dir, 0700); verifyDir(dir) (Lstat; must be a directory and not a symlink/reparse point; on Unix the owner uid must equal getuid() and if perm&0o077 != 0 it is Chmod 0700 then re-Lstat; anything else returns an error). For each File: refuse empty Data with an error; Lstat the final path; keep it only if it is a regular file, owned by us (Unix), without group/other write bits, and its streamed sha256 equals Sum; otherwise write it fresh with fileutil.WriteFileAtomic(final, Data, 0700 if Exec else 0600) (which closes the temp before rename, Pitfall 14). A symlink at the final name is replaced by the rename, never followed.
- owner_unix.go (//go:build !windows): fileOwnedByUs / dirOwnedByUs via fi.Sys().(*syscall.Stat_t).Uid compared with a package var getuid = os.Getuid (test seam). owner_windows.go: ownership always true; reject FILE_ATTRIBUTE_REPARSE_POINT via fi.Sys().(*syscall.Win32FileAttributeData) or ModeSymlink/ModeIrregular; document that %LocalAppData% carries a user-only inherited ACL (Pitfall 9).

In embed_prod.go keep //go:embed child/child as childBinary, delete extractChild and its shared-temp-dir extraction code, and add childSource() (data []byte, sum [32]byte, err error) returning the embedded bytes with a sum from a package-level sync.OnceValues (D-02); an empty embed returns an error.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| other local users → shared temp/cache paths | can pre-plant files or symlinks where Verdana extracts code |
| launcher → child process | the launcher execs whatever file sits at the path it computes |
| CWD → exec | the current directory may be attacker-controlled (downloads, USB) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-12 | Elevation of privilege | child extraction in shared /tmp | high | mitigate | per-user 0700 cache dir verified for owner/symlink before every spawn (Task 1) |
| T-03-13 | Tampering | reused child file | high | mitigate | full sha256 re-hash before every spawn; mismatch replaced by atomic rename, never executed (Tasks 1-2) |
| T-03-14 | Elevation of privilege | ./child/child CWD fallback | high | mitigate | fallbacks only in embed_dev.go; prod fails closed (Tasks 1-2) |
| T-03-15 | Tampering | symlink at final name or dir | medium | mitigate | Lstat checks; rename replaces a symlink without following it (Task 2 tests) |
| T-03-16 | Denial of service | dir owned by another user | low | accept | fail closed with a visible notice; DoS only, never a hijack |
| T-03-17 | Repudiation | silent fail-closed | medium | mitigate | Error log with cause and path; child-unavailable notice; manager raised (Task 3) |
</threat_model>
