<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI input to same-user socket | Caller supplies secret bytes from stdin/private file in a write request; argv and reads remain public. |
| Config/credential filesystem to daemon | Ordinary config is non-secret; a separate owner-only credential file contains retained material. |
| Service controller to NAP keyer | Replacing an identity must cancel old work and publish only a completed new session. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-10 | Information disclosure | CLI and RPC | high | mitigate | stdin/0600 no-follow file only, no argv secret, narrow status DTO, fixed errors, sentinel leakage tests. |
| T-08-11 | Tampering | credential store | high | mitigate | Owner/mode/regular-file checks, private directory, no-follow open, atomic replace, readback and restart tests. |
| T-08-12 | Elevation of privilege | signer transition | high | mitigate | Serialize switch, cancel prior keyer and pairing, clear identity before publishing replacement, close identity-bound windows. |
| T-08-13 | Information disclosure | config and diagnostics | high | mitigate | Reject secret field names before value formatting and keep Config/Effective/diagnostics public-only. |
| T-08-14 | Repudiation | signer switch outcome | medium | mitigate | Report final connected/disconnected result after keyer public-key check; timeout has unknown-outcome guidance. |
</threat_model>
