<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Same-user socket to window runtime | A client chooses an address and window ID; backend resolves installed identity and owns instance lifetime. |
| Child process to backend | The child can send untrusted bounded wire frames; only the verified napplet host path establishes readiness. |
| Filesystem to child exec/library | Daemon must not run a napplet-supplied binary or load a library from an unsafe path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Spoofing | linuxhost child readiness | high | mitigate | Count only a valid host-page nap.start from the selected child process and fail on early exit/failure; retain per-window bridge token checks. |
| T-08-02 | Tampering | window-program lookup | high | mitigate | Require checked absolute executable and library paths outside napplet assets; reject symlink/irregular or shared-writable path components, preserve child library fail-closed check. |
| T-08-03 | Elevation of privilege | launch service | high | mitigate | Resolve full canonical address to installed record; reuse launchWindow, hardened child host page, and existing nap route gates rather than direct page navigation. |
| T-08-04 | Denial of service | readiness and stop waits | medium | mitigate | Bounded host readiness and stop contexts, child kill/reap, and existing daemon operation leases. |
| T-08-05 | Information disclosure | launch error wire | medium | mitigate | Fixed protocol error and allow-listed session_unavailable reason; discard raw display, executable, and WebKit error text. |
</threat_model>
