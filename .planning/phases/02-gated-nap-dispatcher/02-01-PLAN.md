<objective>
Replace the bare NAP handler map with a route table in which every request type declares its permission gate and its spec-defined failure shape (D-01, D-05), make the dispatcher enforce stored denials before a handler runs (D-04), and guarantee that every request is answered exactly once, in its own shape, including when a handler forgets to reply or panics (D-06, D-08).

Purpose: this is the choke point every later Phase 2 plan builds on. Bounds and rate limits (02-03), gated sinks and the AST guard (02-04), the host page's mirror table (02-05) and prompt cancellation (02-06) all hang off `napRoute`. It also fixes the three wrong failure shapes named in DISP-02: R-2 (relay.publish), ID-2 (identity.getPublicKey) and N-6 (intent.invoke).
Output: `backend/nap_route.go` and `backend/nap_route_test.go` (new), a reworked dispatcher in `backend/nap.go`, the safeGo conversions in five domain files, and an adapted conformance oracle.
</objective>

### The route table (authoritative for this plan's golden test)

Gate constructors (names are this plan's choice under Claude's discretion): `openGate(reason)`, `sessionGate(perm)`, `perCallGate(perm)`, `dynamicGate(reason, perms...)`. Failure kinds and their envelopes (JSON names in parentheses, used by 02-05's host page table):

- none (`none`): never answered
- err (`err`): `<type>.result` with `error` plus static fields
- okFalse (`okFalse`): `<type>.result` with `ok:false`, `error` plus static fields
- okFalseCode (`okFalseCode`): `<type>.result` with `ok:false`, `code`, `error`
- typedErr (`typedErr`): `<type>.error` with `error`
- link (`link`): `link.open.result` with `status:"denied"`, `error`
- intent (`intent`): `intent.invoke.result` with `result:{ok:false, archetype, action, handled:false, error}`; archetype is the request's `request.archetype` when it is a string, else ""; action is `request.action` when it is a non-empty string, else "open"
- default (`default`): `<type>.result` with the static fields only, never an error
- schemaError (`schemaError`): `config.schemaError` with `code` and `error`, both the mapped code
- granted (`granted`): `notify.permission.result` with `granted:false`
- lifecycle (`lifecycle`): `<closed>` (relay.closed or outbox.closed) with `subId` and `reason`; sent only when the envelope carries a string subId

The mapped code is `codes[generic]` when the route maps it, else the generic code itself.
