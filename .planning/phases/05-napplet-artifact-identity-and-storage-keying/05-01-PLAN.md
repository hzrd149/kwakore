<objective>
Make the napplet's full NIP-01 address its id (D-01) and key NAP-STORAGE by (address, artifact hash) with no fallback (D-02), in hex-named files under a napplet-only directory (D-04, D-24), so no two napplets share storage and a root napplet never collides with d=root (KEY-01, KEY-03, KEY-04). Drop the records the old id scheme left in state.json, once, with a notice (D-23, UI-D7).

Purpose: today napplet ids are napplet~{pk16}~{d} (root = napplet~{pk16}~root, the same as d=root), storage falls back to the id when the hash is empty, and storage file names map every odd character to an underscore. After this plan the identity every later plan keys by (config, reclaim, sweep, trial promotion) exists and is the only one.
Output: address ids, the scope helpers, the napplet-storage directory, hex file names, fixed test fixtures, the KEY-03/KEY-04 regression tests and the D-23 load-time drop.
</objective>
