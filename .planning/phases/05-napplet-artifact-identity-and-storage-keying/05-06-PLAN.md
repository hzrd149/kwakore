<objective>
Move the update paths onto the NIP-01 selection helper (D-10), stamp an installed napplet unavailable when its latest event is invalid, refuse to install or try unavailable entries, and add the launch-time freshness check that closes A11 (D-19).

Purpose: CheckForUpdates validates before selecting and uses QuerySingle (one relay's answer), fetchCurrentEvent returns the first event any relay sent, and Update cannot find a version unless a check already cached it (updateCache is never written). CONFORMANCE A11's chosen reading also asks: “at launch, check for a newer event when online without blocking the launch”.
Output: a testable fetch seam, updateStates/latestManifest, Unavailable in Snapshot, refusals, the throttled launch check.
</objective>
