<objective>
Warn at launch when a NIP-5D napplet requires domains Verdana lacks (REG-04, D-15), make a trial window verify every path blob before it opens (REG-03, D-13), and promote trial data only into the version actually installed, never over existing data (KEY-06; D-09, D-25), with the UI-SPEC S4 notices for each outcome.

Purpose: MissingDomains is shown only as a detail row (NIP-5D: “At load the shell checks `requires` against its capabilities; if one is absent it SHOULD reject the napplet or warn.”); tryNapplet downloads only the index blob (NIP-5D: “Fetch each `path` blob from Blossom by its sha256 and verify `sha256(blob)` matches the `path` hash.”); finishNappletTrial installs the trial's possibly stale event and overwrites whatever is stored.
Output: notice infrastructure (ids, copy, sanitizer, ranks, cap), the requires notice, all-path trials, hash-checked promotion, tests.
</objective>
