| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-06-09 | Tampering | Reload transaction | high | mitigate | Parse and validate the complete merged candidate before an atomic pointer swap in config.go. |

| T-06-11 | Information disclosure | Reload warning | medium | mitigate | Warning DTO contains safe config basename/field and fixed validation reason, not raw JSON or AppState. |
