<objective>
Make a napplet document that replaces itself (reload, navigation, document.open) lose its frame and its session, and boot a fresh frame with a fresh session, bounded against reload loops (SBOX-01; D-01, D-02, D-03, D-04 detection half, D-21).

Purpose: today a reloaded or navigated frame keeps talking to the still-established old session (CONFORMANCE NIP-5D-reload, open). After this plan the host page treats every second load as a replaced document and the Go session is torn down at detection.
Output: replaced-document handling and loop cap in napplet-host.js, refusals bound to their sending frame, nap.reset documented as the replacement teardown, node and Go regression tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sandboxed napplet frame -> host page | untrusted documents (including ones that replaced the original) post messages the host page forwards as nap.msg |
| host page -> Go backend | trusted lifecycle rpcs (nap.boot, nap.start, nap.loaded, nap.reset) decide which session envelopes belong to |
| Go backend -> frame | pushes and refusals carry session data back into whatever document holds the frame |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Spoofing | replaced document speaking under the napplet's session (napplet-host.js load hook) | high | mitigate | second load -> replaced(): frame removed and nulled synchronously, nap.reset on the lane, fresh frame and session (Task 1) |
| T-04-02 | Information disclosure | old-session pushes and refusals reaching the new document | high | mitigate | session = null drops old-gen pushes; refusals delivered only to the sending frame; napPushGen needs established (Tasks 1-2) |
| T-04-03 | Elevation of privilege | old session's grants or pending prompt approved into the new document | high | mitigate | resetLocked clears grants and cancels the session ctx that owns prompts; TestPromptCancelledOnReset (Task 2) |
| T-04-04 | Denial of service | reload loop pinning the launcher with boots and sessions | medium | mitigate | 3 rebuilds per 10 s, then halt with in-window text; state unreachable from the frame (Task 3) |
| T-04-05 | Tampering | frame forging lifecycle rpcs | high | mitigate | existing: the frame reaches Go only as nap.msg; nap.reset/nap.start stay host-page-only (no new rpc, D-21) |
</threat_model>
