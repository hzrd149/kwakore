Wire protocol (desktop/child/main.go wireMsg): the child writes one JSON object per line on stdout; an rpc is {"t":"rpc","id":N,"method":M,"params":P} where P is the JSON text of the params (for nap.msg, the host page sends the envelope's JSON as a JSON string, so params decodes to a string that decodes to the envelope). The launcher answers on the child's stdin with {"t":"resp","id":N,"result":R} where R is the raw JSON of the answer (omit result for null) or {"t":"resp","id":N,"error":"..."}; pushes are {"t":"eval","code":"window.__nap_push && window.__nap_push(GEN, JSONSTRING)"}; {"t":"close"} closes the window. nap.boot answers {"srcdoc":..., "title":...}; nap.start answers {"gen":N}; nap.loaded and nap.reset answer null.
Shim storage API: window.napplet.storage.instance.getItem(key) / setItem(key, value) send storage.get / storage.set envelopes with scope "instance" and a uuid id; results are {type:"storage.get.result", id, value} (value null when missing) and {type:"storage.set.result", id}; the shim times storage out after 5 s.
