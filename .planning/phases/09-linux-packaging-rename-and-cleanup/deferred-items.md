- **09-08 (found while rendering the generic user units in the NixOS module):** (1) **`ExecReload=kill -HUP $MAINPID` does not resolve on NixOS.** Nixpkgs patches systemd's compiled-in executable search path (`0004-path-util.h-add-placeholder-for-DEFAULT_PATH_NORMAL.patch`, substituted with systemd's own `$out/bin/`), and systemd's bin has no `kill`. The 09-01 SUMMARY's key decision ("resolved through systemd's search path rather than /bin/kill, so it also works on NixOS") is wrong for NixOS. The generic template is still right for ordinary distributions (`/usr/bin/kill`). `nix/module.nix` renders it with one documented substitution, `kill` -> `${coreutils}/bin/kill`, and `nix/module-test.nix` pins that it is the only difference besides `@BINDIR@`. 09-10's service docs should not repeat the 09-01 claim, and anyone writing units by hand on NixOS must use an absolute kill. (2) **NixOS user services get a pinned PATH by default** (`enableDefaultPath`: coreutils, findutils, grep, sed, systemd), which would hide xdg-open, xclip/wl-copy, notify-send, mpv and vlc from the daemon. The module turns it off so the daemon keeps the user manager's PATH like the generic unit; NixOS still adds `LOCALE_ARCHIVE` and `TZDIR`.
