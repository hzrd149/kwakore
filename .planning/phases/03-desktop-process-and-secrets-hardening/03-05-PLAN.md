<objective>
Replace the localhost TCP single-instance channel with a user-only Unix socket (peer uid checked) or an owner-only named pipe on Windows, and a strict v2 command protocol (PROC-03).

Purpose: another local user can no longer connect to the running launcher to trigger shortcuts, read the world-readable port file, or squat the channel to receive a shortcut token.
Output: desktop/internal/instanceipc (Unix + Windows), v2 router in singleinstance.go, rewritten startup tests, go-winio dependency.
</objective>

## Trust Boundaries

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-23 | Spoofing | other user connecting to the listener | high | mitigate | 0700 dir + 0600 socket + peer uid check on accept (Tasks 1-2); Windows owner-only DACL + reject remote (Task 3) |
| T-03-24 | Information disclosure | channel squatting to receive a shortcut token | high | mitigate | client checks server uid (Unix) / server process SID (Windows, D-18) before writing (Tasks 1, 3) |
| T-03-25 | Tampering | malformed or legacy commands | medium | mitigate | v2 only, known cmd set, token ≤16 KiB, legacy mapping removed (Tasks 1-2) |
| T-03-26 | Denial of service | oversized or slow requests | medium | mitigate | 64 KiB line cap and 5 s deadline per conn (Task 1) |
| T-03-27 | Denial of service | dir pre-created by another user | low | accept | refuse and run without a listener; never a hijack |
