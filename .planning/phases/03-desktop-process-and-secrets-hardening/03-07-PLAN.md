<objective>
Move login secrets behind a SecretStore with a crash-safe, never-regenerate migration from state.json (SECR-01, SECR-02, backend half).

Purpose: secrets leave the plain config file when a keyring exists, and a locked, slow or missing keyring can never cost the user their login or bunker pairing.
Output: launcher_secrets.go state machine, accessor-only secret access in auth code, KeyringWait and keyring-fallback wiring, migration matrix tests.
</objective>
