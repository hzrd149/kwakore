## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| napp/napplet → backend bridge | untrusted URL strings from napp JS reach openExternalLink |
| backend → desktop/mobile host | any backend caller can reach host.OpenLink |
| host → OS opener | xdg-open/open/rundll32 treat schemes and argv specially |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-06 | Elevation of privilege | gioHost.OpenLink with file:/custom scheme | high | mitigate | netguard.ExternalLink in the host itself (Task 1) |
| T-03-07 | Tampering | argv injection via leading "-" or whitespace | medium | mitigate | url.Parse rejects "-https://x"; whitespace/control chars rejected; only u.String() is passed (Task 1) |
| T-03-08 | Spoofing | userinfo links (https://good.com@evil.com) | medium | mitigate | User != nil rejected (Task 1) |
| T-03-09 | Denial of service | zombie opener processes | low | mitigate | startCommand reaps with go c.Wait() (Task 1) |
| T-03-10 | Tampering | saveFile overwriting a file created in between | low | mitigate | fileutil.WriteFileNew + free-name loop (Task 2) |
| T-03-11 | Tampering | approved NAP link refused later (Pitfall 10) | low | accept | refusal is the safe direction; napLinkOpen alignment belongs to the NAP-LINK phase |
